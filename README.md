# シンプル人狼

1台のスマホを順番に回して遊ぶ、GM(進行役)いらずの人狼ゲームです。PWA なので、ホーム画面に追加すると、オフラインでも遊べます。

公開 URL: https://mmishina-art.github.io/simple_jinrou/

## 遊び方

1. 「あたらしく始める」で、人数(4〜12人)・名前・役職の数を決める(人数ごとに、おすすめの組み合わせが入っています)
2. 画面の「○○ さんに渡してください」に合わせて、1人ずつスマホを回し、自分の役職をこっそり確認する
3. **夜**: 1人ずつ回して、こっそり行動する。行動がない人も「怪しい人」を選ぶ(だれが役職持ちか、見分けられないように)
4. **朝**: 襲われた人がわかる(1日目の夜は襲撃なし)
5. **昼**: タイマーを使って話し合い、1人ずつ回して投票する。いちばん票の多い人が処刑される(同じ票数なら決選投票、それでも同じなら抽選)
6. 人狼が全員いなくなれば **村人陣営** の勝ち。生きている人狼の数が人間と同じになれば **人狼陣営** の勝ち

### 役職

| 役職 | 陣営 | できること |
|---|---|---|
| 🧑‍🌾 村人 | 村人陣営 | 特別な力はない |
| 🐺 人狼 | 人狼陣営 | 2日目からの夜に、仲間と1人を襲う。仲間の人狼がわかる |
| 🔮 占い師 | 村人陣営 | 毎晩1人を占い、人狼かどうかを知る |
| 🛡️ 騎士 | 村人陣営 | 2日目からの夜に、自分以外の1人を襲撃から守る |
| 🕯️ 霊媒師 | 村人陣営 | その日に処刑された人が人狼だったかを知る |
| 🃏 狂人 | 人狼陣営 | 人間だが人狼の味方。占われると「人狼ではない」と出る |

## 機能

- 途中で閉じても「続きから」で再開できる(ヘッダーの「やめる」で、そのゲームを消せる)
- 勝敗の記録(村人陣営 / 人狼陣営の勝ち数)と、そのファイルへの書き出し / 読み込み(「記録のバックアップ」)
- 効果音(Web Audio で合成。右上のボタンでオン / オフ)

## 起動方法

```bash
npm ci
npm run dev          # 開発サーバー
npm run verify       # lint → test → build → check:dist
npx playwright install chromium && npm run test:e2e
```

## ファイル構成

- `src/logic.ts`: ルール(役職の配布・夜の行動・投票・勝敗判定)。DOM に触れない純関数。`tests/logic.test.ts` で単体テスト
- `src/setup.ts`: ゲームの準備の画面
- `src/play.ts`: ゲームの進行の画面(渡す画面・役職・夜・朝・話し合い・投票・結果)
- `src/main.ts`: 画面の切り替え・保存・デバッグモードの操作
- `src/dom.ts`: 画面の部品を組み立てる小さな関数
- `e2e/app.spec.ts`: 画面のテスト(4人で1ゲーム遊ぶ、など)

ルールの詳細は [CLAUDE.md](./CLAUDE.md) を参照してください。

## デバッグモード

タイトル画面のバージョンの表示(`v0.1.0`)を続けて 5 回タップすると、左下に操作パネル(DEBUG)が出る。もう一度 5 回タップするか、パネルの「終了」で消える。

- 「村勝」「狼勝」: ゲーム中に、すぐにその陣営の勝ちにする(結果の画面の確認用)

パネルの操作を使った回は、勝敗の記録に残さない。
